## SMTP 密码改为「存数据库」（用户要求：密码同样保存在数据库中）
用户原话「神了，密码同样保存在数据库中大哥」—— 即不要只让密码走环境变量，后台要能直接填、存进库。

- 契约：`shared/mail.ts` 的 `SmtpConfig` 加 **`password?: string`**（D1 里存的是密文；`DEFAULT_SMTP_CONFIG.password = ''`），
  新增 **`publicSmtpConfig(mail)`** —— 返回 `{ ...mail, password: undefined }`，`JSON.stringify` 会丢掉该键，
  所以前端拿到的 mail **连 password 字段都没有**，也就不可能把空值误提交回去。
- 加密：`worker/lib/crypto.ts` 新增 `encryptSecret` / `decryptSecret` / `isEncryptedSecret`：
  HKDF(SHA-256, info=`kingcola.secret`) 派生 AES-GCM 密钥，密文格式 `enc$<iv b64url>.<密文 b64url>`；
  密钥来自 **`SESSION_SECRET`**（不新增环境变量）。**解密失败返回 null 而不抛异常**（换 secret 时不炸接口）。
- 取值逻辑：`worker/lib/mailer.ts` 新增
  `mailPasswordOf(env, config)`（**数据库优先、`SMTP_PASSWORD` 兜底**）、
  `mailPasswordSourceOf()`（`database|env|none`，给后台提示）、
  `resolveMailPassword()`（密文→明文，失败回退并 warn）、`encryptMailPassword()`（保存前加密）；
  `isMailConfigured()` 改为「username 为空就当无需认证」。
- 路由：`routes/config.ts` 的 `resolveRuntimeConfig` 读 KV/D1 后**在内存里解密** ——
  ⚠️ **写进 KV 缓存的是未解密的密文版**，千万别把明文密码放进 KV；
  新增 `publicRuntimeConfig()`，公开接口 `/api/config/runtime` 与后台 `GET /api/admin/config` 都走它；
  `updateAdminConfig` 对密码做**三态**处理（**不带 password 键 = 不修改；空串 = 清除；有值 = 更新**），
  并且先 `delete restRuntime.mail` 再 spread（否则提交上来的明文会进落库对象）；返回体带 `mailPasswordSource`。
- 后台：`src/admin/SettingsPage.tsx`「邮件通知」加密码输入框（`type=password`，placeholder 提示「已保存——留空表示不修改」）
  +「清除已保存的密码」链接，改成独立的 `saveMail()`；状态文案按 `mailPasswordSource` 分三种。
  `endpoints.ts` 的 `AdminConfigResponse.mailSecretConfigured` → **`mailPasswordSource`**，`adminUpdateConfig` 返回体同步。

用户原话：「补录学生时存在严重问题，如果无法立即拿到所有信息，当前也不存在后续补充材料的入口，
考虑在名单处提供一个修改所有资料的入口」「通用设置在进入招新周期后，允许访问这些局部变量的值了」。

- 后端：`IMMUTABLE_KEYS` 去掉 `studentId`（只剩 id/createdAt），`ApplicationPatch` 同步放宽；
  `PUT /api/admin/applications/:id` 支持改 `name`/`studentId`（学号唯一性校验 → 409 `ALREADY_EXISTS`）；
  联系方式只校验格式不强制必填；改了姓名/学号会重算报名表下载名；
  新增 `POST /api/admin/applications/:id/file`（multipart）**后补 / 替换报名表**：同官网一套校验、
  成功后删旧文件、审计记 `replace_application_doc`。
- 笔试现场补录**不再要求报名表**（邮箱/手机/QQ 仍必填）；补录弹窗两种情形都能带表。
- 前端：名单详情弹窗（`AppDetailDialog`）的资料区改为可编辑（姓名/学号/邮箱/手机/QQ + 保存资料），
  报名表一行支持下载 + 选文件即上传/替换；行内按钮改名「详情 · 改资料」，表头文案写明入口。
- 设置页的变量清单改为显示**每个变量此刻的值**（本届的只读；没值显示「还没配置」）。
- 自检：新增 4b 节（后补报名表 / 改全部资料 / 下载名跟着变 / 邮箱格式 / 学号冲突 / 替换指向新文件）
  与「现场补录允许先不交报名表」→ **80 项全绿**。文档 §6.9 新增「六之二、改全部资料」。
